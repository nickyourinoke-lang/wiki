搭建维基百科网站所需工具

本条目梳理从零搭建一个类维基百科（Wiki）网站所需的全部工具与技术栈。

概述

“维基百科”本身是运行在 MediaWiki 引擎上的。但今天搭建一个维基站点，你并不必从零写程序——市面上有成熟的 开源引擎、托管平台 与 容器方案。搭建一套可公开访问、支持多人协作编辑的维基，通常需要下面六类工具：引擎、运行环境、主机与域名、存储与媒体、协作与防滥用、备份与运维。

1. Wiki 引擎选型

引擎决定你用什么语言、数据库，以及后续扩展的难易。主流选择：

引擎技术栈数据库上手难度适合
MediaWiki（维基百科同款）PHPMySQL / MariaDB中大型、强结构化的知识库
Wiki.jsNode.jsPostgreSQL / MySQL / SQLite低现代 UI、Markdown 优先
DokuWikiPHP（无需数据库）纯文件低轻量、内网文档
BookStackPHP / LaravelMySQL低书籍式手册
XWikiJava内置/HSQL/MySQL高企业级应用平台
💡 新手建议从 Wiki.js（或 DokuWiki）起步；若要做“另一个维基百科”，选 MediaWiki 最贴近。

2. 运行环境

引擎跑起来需要对应的运行时与 Web 服务器：

  • Web 服务器：Nginx（推荐）或 Apache，负责反向代理与静态资源。
  • 语言运行时：MediaWiki / DokuWiki / BookStack → PHP 8.1+；Wiki.js → Node.js 18+。
  • 数据库：MySQL 8 / MariaDB 10.6+ 或 PostgreSQL 14+。
  • 必需扩展：PHP 侧需 mbstring / gd / intl / curl / xml 等（MediaWiki 安装向导会自检）。

3. 主机与域名

  • 主机：1 核 2G 的云服务器（VPS）即可起步；流量增长再纵向扩容。
  • 域名：到域名注册商购买并完成 ICP 备案（中国大陆访问必需）。
  • DNS：用 Cloudflare 或厂商 DNS 做 A/CNAME 解析。
  • HTTPS：Let's Encrypt 免费证书 + 自动续期（Certbot / Caddy 自带）。

4. 存储与媒体

维基里图片、附件会越来越多：

  • 小站点直接用主机磁盘 + 定期备份即可。
  • 大站点把上传目录挂到 对象存储（S3 / 阿里云 OSS / 腾讯云 COS）。
  • 面向全球访问可加 CDN 加速静态资源。

5. 内容协作与防滥用

  • 编辑器：VisualEditor（可视化）、Markdown 插件、或原生 wikitext。
  • 账号与权限：内置用户组 + 可选 LDAP / OAuth 接入。
  • 防滥用：验证码（CAPTCHA / Turnstile）、垃圾链接过滤、编辑审核。
  • 搜索：内置搜索；大站可接 Elasticsearch / Meilisearch。

6. 备份与运维

  • 备份：定时 dump 数据库 + 同步上传目录到异地/对象存储。
  • 监控：UptimeRobot / Prometheus 监测可用性与磁盘。
  • 更新：引擎与插件随官方安全公告及时升级。

7. 推荐组合

场景组合
新手 / 个人VPS + Nginx + Wiki.js + PostgreSQL + Cloudflare
经典维基百科复刻VPS + Nginx + MediaWiki + MariaDB + VisualEditor
轻量内网文档DokuWiki（纯文件，免数据库）+ Nginx
