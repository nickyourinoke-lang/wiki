# WorkBuddy Wiki（小黑 / 嘿咻光标版）

一个维基百科风格的静态站点 Demo，用于演示「罗小黑」鼠标光标（静止=小黑，移动=嘿咻）与动画背景。

## 内容
- `index.html` —— 主页面《搭建维基百科网站所需工具》
- `reborn_wiki_bg.gif` —— 动画背景（家庭教师群像夕阳庭院 Cinemagraph）
- `cursor_xiaohei_*.png` / `cursor_heixiu.png` —— 7 种光标状态素材

## 光标状态
| 状态 | 文件 | 触发 |
|---|---|---|
| 小黑（静止） | cursor_xiaohei_idle.png | 鼠标不动 |
| 嘿咻（移动） | cursor_heixiu.png | 鼠标移动 |
| 警觉 | cursor_xiaohei_alert.png | 悬停链接 |
| 暴躁 | cursor_xiaohei_angry.png | 右键 |
| 点击 | cursor_xiaohei_click.png | 鼠标按下 |
| 看书 | cursor_xiaohei_text.png | 焦点在输入框 |
| 睡觉 | cursor_xiaohei_sleep.png | 静止 7 秒 |

直接双击 `index.html` 即可。
